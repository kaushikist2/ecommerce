## E-Commerce Platform (React + Tailwind CSS)

A modern e-commerce UI with cart functionality and product filtering.

### Features
- Product listing with ratings & pricing
- Add to cart / remove from cart
- Cart page with total calculation
- Product filters (rating & price)
- Responsive, aesthetic UI

### Tech Stack
- React
- Tailwind CSS
- Lucide Icons

### Focus
UI/UX, state management, component-driven design
